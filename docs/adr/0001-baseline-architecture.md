# ADR 0001：独立语义核心与按能力分层

- 状态：已采纳为初始工程约束，实际 API 与物理模块仍待实现及验证。
- 日期：2026-10-28。

## 背景

工程需在普通 Android 项目复用，并单独支持 BIL 迁移；BIL、Lumen 和其他 Meguviz 制品的当前合同尚未完成核验。基础库不能依赖这些外部实现或假定未发布接口可用。

## 决定

将纯值模型与核心语义同 Android 运行时分离；model/core 可先作为一个制品内的不同包。共享对象仅限经证明不可变的 Recipe 和语义计划，Drawable、绘制资源和 Binding 按 owner 隔离。简单实色圆角优先直接 Canvas 路径；扩展在冷路径显式注册。Compose、Lumen 和其他桥按真实公开合同作为可选依赖，缺失时基础路径继续可用。

基础目标 API 21+，具体支持声明须经过对应设备和能力验证。软件绘制为基线；没有软件回退的硬件专属能力需要显式协商和拒绝或命名降级。内部语义计划不直接成为公共 ABI，尚未稳定的 backend SPI 标为实验性。

## 后果与验收

此决定避免基础消费者强制引入生态依赖，并要求对状态、几何、所有权、软件能力及独立制品进行分层测试。任何代码存在均不构成 Gate 通过；G2—G5 以工程计划中列出的真实构建、消费者和平台证据为准。后续若需要改变，须补充证据及影响合同的 ADR。

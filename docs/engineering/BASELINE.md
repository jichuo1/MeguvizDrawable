# 工程基线

更新时间：2026-10-28。

- 独立 `core` 使用 Java 8 字节码目标，构建配置使用 JDK 17 和 Gradle Wrapper 9.8.2；Android 通过显式 profile 引入。
- 无生产依赖；状态规则采用首匹配、正负条件、零终止和显式无匹配；圆角采用统一缩放。
- `check` 包含可执行的纯 Java 合同测试；不包含 Android 平台、设备、图像、性能或 ABI 验证。
